BFFSH-dataset: A Dataset for Sentiment Analysis and Hate Speech Detection of Bangladeshi Football Fans’ Comments on the FIFA World Cup 2026 2026
Lead Researcher | GitHub Repository
  • Developed BFFSH-Dataset, an innovative dual-annotated benchmark dataset of 11,565 Bengali social media comments from Facebook and YouTube posts during the FIFA World Cup 2026.
  • Used regex text cleansing techniques along with TF-IDF feature extraction to handle noisy and difficult low-resource Bengali text.
  • Developed and evaluated baseline models (1D-CNN, LSTM, GRU) and sophisticated hybrid models (1D-CNN-LSTM, 1D-CNN-GRU, triple hybrid 1D-CNN-LSTM-GRU) for multi-class sentiment analysis and binary classification of hate speech.
  • Obtained the best results through the optimally designed triple-hybrid model, achieving an accuracy of 82% (F1-score of 0.74) in sentiment analysis and an accuracy of 81% (F1-score of 0.80) in hate speech detection.
A Large-Scale Multiclass Dataset and Comparative Analysis for Bangla Cyberbullying Detection 2026
Supervisor, ResearchBuddy AI | GitHub Repository
  • Consolidated and refined a massive, noisy corpus of 104,218 informal Bangla social media posts, relabeling and structuring the data into a five-class taxonomy.
  • Conducted comprehensive comparative analyses across Classical ML, Deep Neural Networks with Word2Vec and FastText embeddings, and pre-trained multilingual Transformers (BanglaBERT, MuRIL, XLM-RoBERTa).
  • Proved that FastText subword tokenization superiorly handles morphological richness, spelling variations, and OOV words in informal Bangla text.
  • Established a robust new baseline for automated toxic content moderation, with the fine-tuned BanglaBERT model achieving state-of-the-art predictive performance at 87.76% accuracy.
BD-CricketSent: A Dataset for Sentiment Analysis of Bangladeshi Cricket Fans' Comments 2026
Supervisor, ResearchBuddy AI | GitHub Repository
  • Compiled and structured a benchmark dataset, BD-CricketSent, consisting of 25,780 informal Bangla social media comments categorized into a balanced three-class sentiment taxonomy (positive, negative, and neutral).
  • Evaluated classical machine learning models trained on TF-IDF features, deep neural networks (CNN, LSTM, GRU) utilizing Word2Vec and FastText embeddings, and fine-tuned pre-trained Transformer models (BanglaBERT, XLM-RoBERTa).
  • Demonstrated that subword FastText embeddings consistently improved Macro F1 scores over static Word2Vec by effectively handling misspelled and morphologically variant tokens in informal Bangla text.
  • Established that the fine-tuned monolingual BanglaBERT model achieved the highest overall predictive performance, reaching 84.98% accuracy, 85.78% Macro F1, and a 0.97 Micro-AUC.
A Multifaceted Approach to Bangla Speech Emotion Recognition Using Hybrid Feature Fusion and Dimensionality Reduction 2025
Lead Researcher | GitHub Repository
  • Proposed a novel feature fusion and dimensionality reduction framework for low-resource Bangla Speech Emotion Recognition (SER) by combining time-domain, frequency-domain, and time-frequency acoustic features with statistical descriptors.
  • Created a compact multifaceted dataset by individually applying and integrating Principal Component Analysis (PCA), Independent Component Analysis (ICA), and Linear Discriminant Analysis (LDA).
  • Evaluated frameworks across SUBESCO (7 emotions, 7,000 clips) and KBES (9 emotions, 900 clips) datasets using machine learning classifiers with rigorous hyperparameter tuning.
  • Achieved state-of-the-art classification accuracies of 87.14% on the SUBESCO dataset and 97.78% on the KBES dataset.
A Comparative Analysis of Hybrid Deep Learning Architectures for Detecting Schizophrenia from EEG Signals 2025
Lead Researcher | GitHub Repository
  • Proposed and evaluated a novel 24-layer triple-hybrid deep learning architecture combining 1D-CNN, LSTM, and GRU layers for automated schizophrenia diagnosis from multi-channel EEG signals.
  • Designed end-to-end signal preprocessing and data augmentation pipelines involving segmentation, denoising, and normalization to enhance model robustness and generalization.
  • Established comparative performance benchmarks across various neural network models and activation functions, demonstrating superior performance with the ELU activation function.
  • Achieved state-of-the-art predictive performance with an outstanding accuracy of 97.04%, 97% precision, 97% recall, and 97% F1-score.
A Data-Driven Approach to Forecasting Crop Transplantation Periods in Bangladesh Using Machine Learning 2025
Lead Researcher | GitHub Repository
  • Developed a specialized 30-year agro-climatic database (1993–2023) integrating meteorological variables (temperature, rainfall, humidity, sunshine) and agronomic parameters for 103 major crops across 35 weather stations in Bangladesh.
  • Trained and evaluated K-Nearest Neighbors, Decision Tree, and Random Forest classifiers using 10-fold cross-validation to predict optimal, climate-resilient crop transplanting months.
  • Achieved a state-of-the-art classification accuracy of 98.95% using the optimized Random Forest model, overcoming severe class imbalance to maintain a consistent F1-score of 0.99.
  • Conducted robust baseline verification against a ZeroR classifier, demonstrating an 80% accuracy improvement over trivial majority-class prediction and validating the model's reliability for future intelligent agro-advisory systems.
